# Release Checklist

## Security

- [ ] Authentication, revocation, and ownership checks verified
- [ ] Validation and rate limiting verified
- [ ] No secrets committed
- [ ] No answer keys exposed
- [ ] Rewards are server-controlled and idempotent

## Mathematics and learning

- [ ] All 16 techniques cross-validate
- [ ] Explanations and normalization are tested
- [ ] Practice, XP, mastery, streak, recommendations, review, and challenge flows pass
- [ ] No unsafe evaluation exists

## Operations

- [ ] Backend tests, frontend typecheck/lint/build pass
- [ ] Production audits reviewed
- [ ] Health/readiness behavior verified
- [ ] Environment variables documented
- [ ] Docker/deployment checks performed or explicitly unavailable

## Open source

- [ ] README, API, architecture, contribution, security, and technique docs are current
- [ ] Code of Conduct and GitHub templates are present
- [ ] License reviewed with project owner
- [ ] No unrelated or pre-existing user changes were overwritten
